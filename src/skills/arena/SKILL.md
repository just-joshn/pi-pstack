# arena

Use `pstack_delegate` mode arena with one shared task, same acceptance rubric, and the configured panel. Use isolated worktrees for writing; read-only workers for analysis. The tool selects a configured judge from a different model vendor than the parent and all candidates, runs a blinded review, and stores full transcripts. Inspect the candidates and judge evidence, choose a base, integrate useful parts manually and verify the combined artifact. If no cross-provider judge is configured, stop rather than claiming independent judgment.
