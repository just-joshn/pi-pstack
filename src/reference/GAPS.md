# Parity and verification gaps

This is a map-based implementation, not a tested port of every original upstream skill. The source attachment is the acceptance inventory. `PARITY.md` and `parity.json` classify every node; classification is not a behavior test result.

| Area                           | Implemented                                                                                                         | Remaining                                                                                                                                                      |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Catalog                        | All source IDs, relationships, view definitions and original source URLs; native select-based browsing.             | Source map graphical coordinates are preserved, not rendered pixel-for-pixel in the terminal.                                                                  |
| Ordinary skills and principles | 77 native SKILL.md entries; map-based instructions.                                                                 | Original full pinned leaf files, scripts and reference templates not downloaded; model-mediated behavior not exercised.                                        |
| Playbooks                      | 22 ordered, evidence-tracked routes; conditional graph links retained.                                              | Reconstructed steps rather than exact full upstream sequences; no deterministic enforcement of every skill invocation.                                         |
| Models                         | Registry selection, nine roles, budget and aliases, cross-vendor judge.                                             | Exact Cursor defaults/legacy migration and service-specific fast models have no reliable native model-ID correspondence.                                       |
| Workers                        | Fresh local Pi CLI sessions, tool allowlists, isolated write worktrees, bounded parallelism, artifacts.             | No hosted Cursor-equivalent remote agent execution, true security sandbox, background worker resumption, or live model tests.                                  |
| Arena/eval                     | Candidate sessions and blinded projections, cross-vendor selection, read-call audit.                                | Strong blinding, artifact-level blind eval, per-provider independence and full transcript coverage are not proven.                                             |
| Goals/loops                    | Native extension goal state and bounded local wakes; restores paused.                                               | No always-on daemon or autonomous wake after Pi exits.                                                                                                         |
| PRs                            | GitHub CLI state and approved exact-head merge prefix.                                                              | Live forge tests, automatic verification provenance, actual Origin implementation, hosted Bugbot not supplied.                                                 |
| Verification                   | Real-surface/formal verifier creation and maintenance instructions.                                                 | App-specific scripts and proof tools must be configured and tested. No bundled browser controller, TLA+ checker, or terminal profiler.                         |
| Team Kit                       | Direct and optional skills, two reviewer contracts, two rules appended to every system prompt.                      | Rules are advisory, not an automatic lint implementation; interactive review HTML/video generated per project, not a bundled template/renderer.                |
| Benny                          | Dormant configuration, workflow drafts, signed event entrypoint, thread-level deduplication, narrow tool allowlist. | External Slack event adapter, scheduler, tracker/MCP tool implementation, app adapter, trusted marker publishing, live triage/repro and draft PR verification. |
| Optional Grok Bot              | Native workflow instructions.                                                                                       | Existing Grok Bot, webhook and Tailscale service must be available.                                                                                            |
| Native Pi runtime              | Typechecked against Pi 1.6.0; local RPC smoke covers discovery and mode persistence without model calls.            | Authenticated model, forge and MCP runs are not covered by the local checks.                                                                                   |

No runtime dependency on Cursor or a third-party coding-agent framework. External project tooling and services are normal conditional dependencies, not Pi runtime substitutes. Full functional parity and production readiness remain unverified. Do not equate 162 mapped nodes with 162 proven implementations.
