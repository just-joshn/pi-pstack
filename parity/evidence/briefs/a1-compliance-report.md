## 4. Ranked fix list

Ranked first by broken install/mode or security-relevant behavior, then direct Pi contract violations, then style/verification. “Accepted adapter” entries have no native Pi equivalent and are not claims of core parity.

1. **Load bundled agents on package installs.** Add the package-root `agents/*.md` directory to the custom loader; otherwise Task names such as `poteto-agent`, `pstack-general`, `pstack-reader`, and Comment Sicko are absent unless separately copied into the user agent directory.
2. **Load child guards from the package, not `<agentDir>/extensions`.** Resolve `extensions/pstack-guards.ts` relative to the extension module and pass it to every child. The current path can disappear in isolated/custom agent dirs; also do not imply that the `Shell` tool or a git worktree provides a security boundary.
3. **Make modelScope configuration actually load.** Read `getAgentDir()/extensions/pstack-agents.json` and top-level `modelScope` as `setup-pstack` writes, or change both sides consistently. Current enforcement silently sees no policy.
4. **Resolve package and user paths portably.** Remove unexpanded `<pstack>` and `~/.pi/agent/...` runtime instructions; use skill-relative paths and `PI_CODING_AGENT_DIR`/`getAgentDir()`. Include guard root, pstack-mode reminders, setup-pstack’s `AGENTS.md`/config writes, and Comment Sicko’s skill references.
5. **Do not label a local worktree as a Cursor cloud agent.** Either implement a real remote backend (no documented Pi cloud API exists) or rename/document the behavior as local worktree execution. The package decision log records a Task killed with 143 when Pi quit; durable survival remains unconfirmed and needs a quit/restart proof if promised.
6. **Throw for real Task/Shell/Await/goal execution failures.** Returned `isError: true` is not in `AgentToolResult` and runtime treats fulfilled returns as success. Keep ordinary text for expected fallback/cancellation; use actual throws for failures.
7. **Bound model-facing Task/Shell output.** Truncate excerpts and point to the full transcript/output log to prevent oversized results.
8. **Propagate nested Task usage.** Aggregate child `Usage` into the outer tool result so session token/cost totals are accurate.
9. **Fix the declared package check.** `npm run check` invokes absent `parity/lint-package.mjs`; add it or remove the broken script/gate.
10. **Serialize todo mutations.** Add `executionMode: "sequential"` for the closure-level mutable `todos`/`nextId` state; retain a concurrent-call regression test despite the official example’s omission.
11. **Remove or implement `Task.machine`.** The schema accepts it but parsing always throws. Exact Cursor parity is unconfirmed because the requested CLI surface notes are missing.
12. **Honor agent-level `is_background` or state the mismatch.** Cursor’s packaged `poteto-agent` marks itself background; Pi currently ignores the frontmatter and requires a per-call `run_in_background` flag.
13. **Accepted custom adapters, no native drop-in:** `Task`/`Await`/`Shell`, `/loop`, `/goal`, and sticky mode are extension-defined behaviors built on documented Pi registration, session, UI, and lifecycle APIs. Keep their contracts explicit; a native Pi replacement for remote cloud agents, process notifications, durable goals, or background jobs surviving Pi exit was not found in the required docs/examples.
