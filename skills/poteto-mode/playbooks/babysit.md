# babysit

Trigger: PR conflicts, comments or red CI.

## Ordered steps

1. Identify forge, PR number, current head and merge base.
2. Read current PR checks, conflicts and review comments.
3. Investigate failures; reproduce each bot finding before fixing or dismissing.
4. Run checks again after each patch; never equate old-head green with current green.
5. Report merge readiness and blockers; do not merge.
