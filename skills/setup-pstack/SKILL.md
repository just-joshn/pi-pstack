# setup-pstack

Use `/setup-pstack` to view the available models and configure the nine named role selections. The native extension saves JSON with defaults version 3 and the selected budget; it does not change the parent model. The Pi aliases auto and inherit-parent resolve to the current parent model for fresh child CLI sessions. Configure an arena judge from a different model vendor than the parent and all candidates. Confirm before saving. Offer to create real or formal verification skills if missing.
