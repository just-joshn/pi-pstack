# Upstream reference

Unmodified copies of the Markdown and rule files from [cursor/plugins](https://github.com/cursor/plugins/tree/41e400932eca14f289e7db717a70455256b6d388) at commit `41e400932eca14f289e7db717a70455256b6d388` (pstack 0.15.48, Cursor Team Kit 1.2.0). Each file under `src/` that ports one of them must keep its sections and numbered steps, and `tests/upstream.test.ts` checks that. Statechart test reports, images and helper code are left out.
